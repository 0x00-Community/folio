# 路线图：和桌面版 Word 的差距

记录于 2026-11-23。对比对象是桌面版 Word。依据是当时读过的模型、命令和界面文案；标了“未验证”的条目只确认了界面上没有入口，
没有逐项验证底层能不能做。做完一项就在这里勾掉，并写上提交。

状态标记：`[ ]` 未开始，`[~]` 进行中，`[x]` 已完成。

## 一、基础编辑的缺口

最影响日常使用，优先做。

- [x] **字符格式**：字体颜色、高亮、上标、下标、清除格式都有了控件。清除格式只去掉直接的字符格式并保留超链接，
  不改段落属性（Word 的按钮还会重置段落样式，这里不重置，结果才好预料）。下标是 `mod+=`，上标是 `mod+shift+plus`
  （Shift+= 在页面上送来的键是 `+`），清除格式是 `mod+space`。格式刷、字符间距仍未做。
- [x] **段落格式**：行距、段前段后、左右缩进、首行和悬挂缩进都有了菜单和段落对话框，确定一次记一条撤销。
  字符单位的首行缩进可以改，原生保存能写回并读回 `w:firstLineChars`。最小值行距可以保存。
  分散对齐仍在模型里，保存会拒绝；段落对话框不再提供这个选项，只有当前已经是分散对齐时才显示，不改就不写。
  制表位、标尺、段落边框和底纹仍未做。
- [ ] **查找和替换**：现在只有自动化接口里的 `find`。要有查找、替换、全部替换，之后是导航窗格。
- [ ] **剪贴板**：代码存在但从未在真实环境里验证；粘贴只走纯文本。先验证复制、剪切、粘贴，再做带格式粘贴
  （从本应用、从网页、从 Excel），最后是选择性粘贴。
  选中图片后复制，剪贴板现在是空的，也归这一项。
- [ ] **输入法**：组字过程从未验证，无界面会话驱动不了输入法。对中文用户是第一位的，需要人在真实窗口里试。
- [ ] **超链接**：插入、编辑、移除、跳转。模型里链接是只读的。导入后的表现未验证。

## 二、文档结构

现在大多“看得见、改不了”。

- [ ] **页眉、页脚、页码**：导入后能显示，但只读。要能编辑，能插入页码。
- [ ] **脚注、尾注、批注**：现在作为不认识的内容原样保留，不能新建、编辑或回复。
- [ ] **域和目录**：页码这类域只显示结果；目录不能生成和更新。
- [ ] **分节和分栏**：能改每节的纸张和页边距，不能插入分节符，没有分栏。
- [ ] **样式**：只能套用已有样式，不能新建或修改，没有样式窗格。
- [ ] **多级列表和编号**：只有项目符号和一种编号。缺多级编号的定义、重新开始编号。中文公文和论文常用。

## 三、表格和图片

- [ ] **表格**：只有增删行列。缺合并和拆分单元格、拖动调整列宽行高、边框和底纹、单元格对齐、表格样式、标题行重复。
- [x] **图片的缩放和拖动**（`9adc689`）：选中、8 个手柄缩放、拖到正文另一处。图片仍是行内的。
- [ ] **移动文档里原有的图片**：现在只能缩放。套件没有原样搬动一个图形的调用，要先在套件里加。
- [ ] **图片的其他能力**：浮动和文字环绕、自由摆放、裁剪、旋转、替换图片、题注。
- [ ] **其他对象**：形状、文本框、图表、SmartArt、公式都不能创建和编辑，文档里原有的会被原样保留。

## 四、审阅和协作

- [ ] **修订**：没有修订模式。含修订的段落现在被锁定。已有修订在界面上怎么呈现未验证。
- [ ] **批注**：见第二大项，只保留、不可操作。
- [ ] **比较文档、保护文档、限制编辑**。
- [ ] **拼写和语法检查**，以及字数统计的细项（现在只有总数）。

## 五、视图、输出和文件

- [ ] **视图**：只有页面视图加缩放。缺大纲视图、导航窗格、标尺、网格线、并排多页。
- [ ] **打印**：有预览和导出 PDF，没有真正的打印（选打印机、页码范围、双面）。
- [ ] **文件**：只支持 `.docx`。不能打开 `.doc`、`.rtf`、`.txt`，没有模板、自动保存、崩溃恢复、最近文档列表。
- [ ] **排版一致性**：编辑视图自己分页，和打印预览每页可能差一两行。Word 是所见即所得。

## 建议顺序

1. 第一大项里的字符格式和段落格式（控件），然后查找替换。
2. 验证剪贴板和输入法，再补带格式粘贴。这两项不通，其他功能再多也没法给中文用户日常用。
3. 表格的合并单元格、列宽、边框。真实文档是政府表格，这是硬需求。
4. 页眉页脚编辑和页码。
5. 多级编号和样式修改，然后是目录。
6. 修订和批注。工作量最大，涉及套件、模型和保存校验，单独立项。
